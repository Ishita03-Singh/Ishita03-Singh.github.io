Backend · Reliability

A queue failure that needed a restart every day

Problem
A RabbitMQ event-handling failure kept coming back, so someone had to restart the service by hand every day.
What I did
I traced the root cause across both the code and the surrounding architecture, and fixed it at the source instead of scripting the restart.
Outcome
Continuous 20 events/sec throughput was restored, and the daily restart went away completely.
  • RabbitMQ
  • .NET
  • Event-driven architecture
  • Root-cause analysis

Backend · .NET

User management & audit-logging module

What I did

Outcome
Every user action is now tracked per user and per entity across the platform's user and permission model.
  • C# / .NET
  • Clean Architecture
  • PostgreSQL
  • Data modelling
